# 增长战略

## 类别领导力

AICore 能够围绕自适应计算机智能和整机协调建立可识别的产品类别。强大的类别所有权能够形成长期品牌与知识产权价值。

## 整机市场扩展

产品可以支持消费、专业、游戏、创作和企业设备系列的差异化体验。产品组合授权能够帮助商业所有者通过成熟硬件渠道扩大价值。

## 企业市场扩展

AICore 可以发展为面向企业的高端方案，重点覆盖生产力、一致的用户体验、组织重点和智能终端价值。

## 生态合作

与芯片企业、操作系统平台、软件提供商和设备制造商建立合作，可以扩大市场覆盖并增强 AICore 的价值主张。

## 垂直市场

高价值机会包括创意制作、工程、本地 AI、技术工作站、教育、企业托管设备和专业计算。

## 商业扩展

| 路径 | 价值潜力 |
|---|---|
| 产品收购 | 统一所有权并加速市场执行 |
| 技术授权 | 在设备和合作伙伴产品组合中创造收入 |
| 高端服务 | 提供持续的企业与专业市场价值 |
| 联合品牌方案 | 共享市场渠道并形成差异化客户体验 |
| 垂直版本 | 为重点客户群提供更高价值方案 |

## 长期机会

随着个人计算机变得更加异构并以 AI 为中心，AICore 可以成为把先进设备能力转化为易理解、自适应且对客户有价值体验的产品层。
