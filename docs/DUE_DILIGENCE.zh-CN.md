# 收购与尽调

## 创始人主导的项目来源

AICore 是一项独立开发的个人项目，创始人直接参与产品定义、软件开发、资料建设、品牌方向和商业战略。

这使潜在买方能够直接联系掌握项目知识的负责人，并有助于高效开展评估和交接。

## 公开层与保密层

公开展示说明产品类别、市场价值、项目结构、商业可能性和信任原则。更深入的产品材料面向合格意向方，并在适当的保密安排下提供。

## 可供合格意向方审阅的材料

| 评估领域 | 可供了解的内容 |
|---|---|
| 产品 | 愿景、定位、应用场景、客户价值和产品组合契合度 |
| 软件资产 | 私有项目整体、开发历史和产品演进 |
| 知识产权 | 所有权讨论、资产范围、品牌材料和转让方式 |
| 平台战略 | 跨平台方向、生态角色和合作机会 |
| 产品体验 | 代表性用户旅程的演示与说明 |
| 商业化 | 收购、授权、企业、整机厂商和合作路径 |
| 交接 | 创始人知识转移、产品说明和连续性规划 |

## 建议洽谈流程

1. 初步战略沟通与买方契合度评估
2. 建立双方保密安排
3. 受控产品与资产审阅
4. 商业结构与交接规划
5. 正式协议与约定的知识转移

## 收购范围

根据协商条款，收购讨论可以覆盖 AICore 名称、品牌资产、软件知识产权、产品资料、商业材料和创始人支持的交接知识。

## 可信度原则

- 公开表述聚焦产品与市场价值。
- 保密证据直接向合格意向方提供。
- 项目历史形成可追溯的开发叙事。
- 创始人能够说明产品决策并支持知识转移。
- 商业范围和相关权利通过交易流程形成文件。
