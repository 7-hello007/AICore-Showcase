# AICore

![AICore 愿景](assets/aicore-vision.png)

## 面向下一代个人计算的自适应智能

AICore 是一款帮助计算机更智能地响应用户重点、应用需求和设备状态变化的软件产品。它面向日益多样化的计算资源提供统一的产品体验，把复杂的系统条件转化为清晰、自适应的结果。

## 产品定位

AICore 定位为 AI PC 时代的 **AI 计算机控制层**。它通过更高层次的情境协调，与操作系统、硬件平台和应用形成互补。

该产品面向希望通过智能、响应速度、效率以及跨设备产品组合的一致体验实现差异化的组织。

## 工程概览

AICore 采用模块化 Rust 工作区进行开发，面向 Windows 和 Linux。主要工程领域覆盖平台遥测、工作负载情境、应用与任务接入、AI 辅助预测、策略验证、运行协调、平台执行、状态读回、回滚、记忆、插件、本地通信和面向用户的运行应用。

系统遵循完整控制生命周期：

```text
观察 → 理解 → 预测 → 决策 → 验证
     → 路由 → 执行 → 核验 → 恢复 → 学习
```

平台专属行为与平台中立的决策逻辑相互隔离。AI 提供建议和理解能力，经过验证的控制与恢复过程保持确定性。公开工程视图详见[高层项目结构](docs/PROJECT_STRUCTURE.zh-CN.md)。

## 市场问题

现代计算机同时包含通用计算、图形计算、专用 AI 加速、内存、电源和温控等资源。各部分可能都很强大，但整体体验往往分散在不同应用、厂商工具和固定运行模式之间。

AICore 通过一致地理解当前重点，并围绕重点协调设备体验，解决这种碎片化问题。

## 核心价值主张

- **情境感知计算：** 根据用户重点和当前工作负载调整体验。
- **整机协调：** 把计算机作为一个智能整体，而不是彼此孤立的部件集合。
- **跨平台潜力：** 支持覆盖多种操作系统和硬件产品组合的广泛产品战略。
- **本地智能：** 为贴近用户、响应迅速并重视隐私的体验创造机会。
- **合作扩展能力：** 为整机厂商、企业、软件和芯片合作提供基础。
- **灵活商业化：** 可支持授权、战略收购、捆绑方案和增值服务。
